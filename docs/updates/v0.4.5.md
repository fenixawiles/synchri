# Synchri v0.4.5 — Protected Copilot connection test

This patch release adds a protected connection test for the current GitHub
Copilot CLI, removing the setup dead end that previously left an installed
and authenticated Copilot runtime permanently unconnected.

**Status: implemented and release-ready.**

## Baseline

- **Previous version: v0.4.4**, tagged at commit
  `a9acf6c1c10209bbd0758194950655f33a0943af`.
- This patch ships as **v0.4.5** from branch
  `codex/fix-copilot-canary`.

## Scope

- [x] GitHub Copilot CLI `1.0.80` and newer can run Synchri's protected
  connection canary.
- [x] The canary gives Copilot an explicitly empty tool set, so it cannot use
  file, shell, web, MCP, or delegation tools.
- [x] The canary runs with an isolated temporary `COPILOT_HOME`, preventing
  personal configuration, plugins, skills, saved permissions, or MCP servers
  from joining the test.
- [x] Built-in MCP, custom instructions, remote control/export, auto-update,
  experimental behavior, `BASH_ENV`, user questions, and automatic temporary
  directory access are disabled for the canary.
- [x] Copilot Planning Mode remains unavailable until a useful read-only tool
  set receives its own enforcement review.

## Verification record

- Copilot remains correctly described as plain-output with no maintained
