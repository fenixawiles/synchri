# Synchri v0.5.0 — Minimalist shell, progressive start, neutral color

This update redesigns the interface around restraint: a business-calm
development environment rather than a terminal cosplay. One global,
collapsible sidebar carries navigation, workflows, recent sessions, and — 
inside a session — that session's rail. Pages lead with the next immediate
task instead of exposing everything at once. Color becomes neutral ink with
one muted steel accent; green/amber/red survive only where they carry meaning.

**Status: implemented; full suite green (702 passed).**

## Scope

- [x] **Neutral ink color system.** All eleven token blocks retuned (bare
  root, the byte-identical system-light block, and nine named themes).
  Primary buttons are inverted ink via new `--btn`/`--btn-ink` tokens; a
  muted steel accent marks focus, links, selection, and live state; new
  `--ok`(-soft/-line) tokens carry success. Pills are neutral by default and
  positive only with an explicit `ok` modifier. Every theme passes a WCAG
  contrast audit (ink ≥ 7:1, secondary text ≥ 4.5:1, status hues ≥ 4.5:1,
  hint text ≥ 3:1). The blinking-cursor brand is retired.
- [x] **Global collapsible sidebar** replaces the top header. It holds the
  brand, the New session action, Overview, quick-run workflows, the compact
  recent-sessions list (with rename/delete/new-in-repo menus), and the
  utilities (share, updates, theme, GitHub account, workspace path). Collapse
  removes it from layout and the accessibility tree; the reveal control is
  `aria-expanded`/`aria-controls` wired, narrow screens get an overlay with
  backdrop, Escape, and close-on-navigate.
- [x] **One context-aware sidebar in sessions.** The session rail (status,
  timebox, gates progress, tab navigation, team presence, controls) renders
  into the sidebar — no double chrome. Collapsing it gives the conversation
  the full window.
- [x] **Home is a start surface.** An attention strip lists only actionable
  states (awaiting join/acknowledgment, paused) and active sessions; saved
  workflows are flat launcher rows; agent connections compress to quiet
  status lines. Session history lives in the sidebar.
- [x] **Progressive new-session flow.** Five questions asked one at a time —
  What are we working on? → Where should the agents work? → What do you want
  done? (paste a brief, or *Help me make a plan*) → Who should work on it? →
  Ready/Start. Answered steps collapse to one-line summaries with Change;
  the team step always expands once with the recommendation preselected and
  per-runtime readiness shown; changing the repository resets the
  repository-scoped answers; choosing planning visibly supersedes the
  workspace answer (and restores it on return to build); an unfinished flow
  survives sidebar navigation and returning from Edit workflow.
- [x] **No saved workflow required.** A build can start with the recommended
  team (Claude builds, Codex reviews) via the existing explicit-agents
  support in `/api/quick-start`; planning routes through the first-class
  draft API (`draft/reset` → `draft` → `start` with a single-shot
  `quick-plan` key used only inside the Start click).
- [x] **Flat surfaces, strong typographic hierarchy.** Cards and boxed
  sections in the primary flows became hairline-separated groups; mono type
  is reserved for technical values (paths, branches, ids, chains, diffs);
  kickers are letterspaced sans.
- [x] The retired wizard flow is untouched, and every externally asserted
  behavior string, API route, and the theme token structure are preserved.
