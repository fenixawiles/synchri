# Synchri v0.4.6 — Clearer setup and session recovery

This patch release makes first-run setup explicit, restores repository
discovery, and lets a person safely restart an active managed session without
discarding its durable work.

**Status: implemented and release-ready.**

## Baseline

- **Previous version: v0.4.5**, tagged at commit
  `de0cb203f2e501dd7138e53213a3804f4d38ff0c`.
- This patch ships as **v0.4.6** from branch
  `codex/fix-setup-repo-restart`.

## Scope

- [x] Runtime setup distinguishes an installed, authenticated CLI from one
  whose tool permissions still need to be completed.
- [x] Connection cards explain the next required action and keep connection,
  failure, and not-yet-connected states distinct.
- [x] Claude Code setup detects saved allow rules and gives concrete guidance
  when tools are not yet authorized.
- [x] Local repository discovery includes Desktop and Documents alongside the
  conventional code folders.
- [x] GitHub repository browsing uses the signed-in user's visible repository
  feed, falls back to public repositories when needed, and no longer links to
  an unavailable GitHub App installation page.
- [x] The repository URL or local-path input remains visible as a dependable
  path even when automatic discovery returns no choices.
- [x] Active fully managed sessions have a bounded Restart action that replaces
  agent processes while preserving the room, history, contract, worktree, and
  participant identities.

## Verification record

- Full Python suite: **697 passed**.

- Repository and setup coverage verifies GitHub fallbacks, visible manual
